# Sohojkor repository release discipline

Follow `docs/RELEASE_READY_DEVELOPMENT.md`. Existing ready PRs stay ready during ordinary reconciliation: batch local changes, test, integrate current Main once, then use `node scripts/ci/ready-pr-update.mjs PR_NUMBER` and `--apply` when the candidate is ready. For connector-based updates use the same checks, one expected-head non-force ref update, and no draft/ready mutations. An unchanged head needs no push. Do not mass-rebase or generate runs merely to demonstrate CI. Keep truly unfinished draft PRs draft until ready; mark ready once. Do not weaken required tests, branch protections, exact-source provenance, independent recovery or production verification. Preserve parallel owners and only release compatible tested slices. Never inspect or modify Nadia-owned work.
